ONMOGELIJK?

Privacy

ONMOGELIJK? is een initiatief van Je Kern tot Bloei. Je kunt beelden en vragen bekijken zonder account en zonder antwoorden of andere persoonlijke gegevens in te vullen.

Wat de app gebruikt

De app gebruikt geen analytics, trackingcookies, externe scripts, externe lettertypen of externe API’s. Afbeeldingen en kaartgegevens worden vanaf dezelfde website geladen. De app plaatst geen cookies en gebruikt geen localStorage of sessionStorage. De vraagvolgorde wordt alleen tijdelijk in het geheugen van de geopende pagina bijgehouden.

Hosting door GitHub Pages

GitHub Pages verzorgt de hosting. Bij het bezoeken van de website ontvangt GitHub technische verbindingsgegevens, zoals je IP-adres en de opgevraagde bestanden. GitHub kan deze verwerken voor de levering, beveiliging en werking van de hosting. Je browser kan bestanden in zijn normale cache bewaren.

Meer informatie vind je in de privacyverklaring van GitHub.

Links naar andere websites

De link naar Je Kern tot Bloei en de bovenstaande link naar GitHub openen alleen wanneer je erop klikt. Daarna geldt het privacybeleid van de betreffende website. Deze website stuurt daarbij geen verwijzende pagina-URL mee.

Vragen over dit initiatief? Je kunt contact opnemen via de website van Je Kern tot Bloei.
